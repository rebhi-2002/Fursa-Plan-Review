## 🔴 أولوية عالية

### ع1 — لا يوجد فحص "أتمّ التوظيف" في الـ API
**المشكلة:** مسارات الـ API تتحقق من الدور فقط ولا تتحقق من إكمال التهيئة. مستخدم يتجاوز صفحة الـ onboarding يستطيع نظرياً استدعاء الـ API.
**الحل:** إضافة فحص `onboarded: true` في middleware الـ `requireRole`.
**الملفات:** `artifacts/api-server/src/middlewares/auth.ts`

### ع2 — لا يوجد حذف حساب للباحث أو صاحب العمل
**المشكلة:** المستخدمون لا يستطيعون حذف حساباتهم. فقط الأدمن يستطيع تعطيل الحساب.
**الحل:** إضافة مسار `DELETE /api/me` وزر "حذف الحساب" في صفحة الملف الشخصي مع تأكيد.
**الملفات:** `artifacts/api-server/src/routes/me.ts`، صفحات الملف الشخصي

### ع3 — لا توجد واجهة لتغيير كلمة المرور أو البريد
**المشكلة:** لا يوجد رابط أو نموذج لإدارة الأمان في صفحات الملف الشخصي.
**الحل:** إضافة قسم "الأمان" يعرض مكوّن Clerk لإدارة الحساب.
**الملفات:** جميع صفحات `*/profile.tsx`

## 🟡 أولوية متوسطة

### م1 — لا توجد صفحة لتصفح أصحاب العمل
**المشكلة:** يوجد ملف تعريفي لكل صاحب عمل منفرداً لكن لا توجد صفحة "تصفح أصحاب العمل".
**الحل:** إضافة مسار `GET /api/public/employers` وصفحة `/employers` بشبكة بطاقات.
**الملفات:** `artifacts/api-server/src/routes/publicJobs.ts`، صفحة جديدة `employers/index.tsx`

### م2 — الإغلاق التلقائي للوظائف بعد انتهاء المهلة لا يعمل
**المشكلة:** الوظائف التي مضى على موعدها النهائي لا تُغلق تلقائياً.
**الحل:** إضافة مهمة دورية (cron) كل ساعة تُغلق الوظائف المنتهية.
**الملفات:** `artifacts/api-server/src/index.ts`

### م3 — لا يمكن تعديل الطلب بعد إرساله
**المشكلة:** الباحث لا يستطيع تعديل طلبه (رسالة التقديم أو السيرة الذاتية) إذا كان لا يزال قيد الانتظار.
**الحل:** إضافة مسار `PATCH /api/seeker/applications/:id` وزر "تعديل" في صفحة الطلبات.
**الملفات:** `artifacts/api-server/src/routes/seeker.ts`، `artifacts/fursa/src/pages/seeker/applications.tsx`

### م4 — لا يوجد ترقيم صفحات في قوائم الطلبات والمستخدمين
**المشكلة:** جميع الطلبات والمستخدمين تُجلب دفعة واحدة بدون حدّ.
**الحل:** إضافة `limit`/`offset` مع "تحميل المزيد" في الواجهة.
**الملفات:** `seeker.ts`، `admin.ts`، الصفحات المقابلة

### م5 — البحث لا يدعم العربية بشكل كامل
**المشكلة:** البحث يستخدم `ilike` البسيط ولا يدعم Full-Text Search للعربية.
**الحل:** إضافة `to_tsvector` و `websearch_to_tsquery` مع فهرس GIN.
**الملفات:** `artifacts/api-server/src/routes/publicJobs.ts`، migration قاعدة البيانات

### م6 — لا يوجد نظام مراسلة بين الباحث وصاحب العمل
**المشكلة:** لا توجد طريقة للتواصل المباشر بعد التقديم. صاحب العمل يرى السيرة الذاتية فقط.
**الحل:** إضافة نظام رسائل بسيط أو على الأقل إظهار بيانات التواصل لصاحب العمل بعد التقديم.
**الملفات:** جدول `messages` جديد أو تحسين صفحة `employer/applications.tsx`

### م7 — إشعارات بريد إلكتروني غير مُفعّلة
**المشكلة:** الإشعارات داخل التطبيق فقط. الأحداث الهامة يجب أن ترسل بريداً إلكترونياً.
**الحل:** دمج خدمة Resend أو Clerk Email في `createNotification`.
**الملفات:** `artifacts/api-server/src/lib/notifications.ts`

## 🟢 أولوية منخفضة

### م1 — مسارات الـ API بدون try/catch
**الحل:** إضافة try/catch حول جميع عمليات قاعدة البيانات مع إرجاع 500.

### م2 — لا يوجد تحقق من نوع الملف في رفع الملفات
**الحل:** إضافة قائمة بيضاء لأنواع MIME المسموحة (PDF, DOC, DOCX).

### م3 — نموذج التواصل غير مرتبط بالـ API
**الحل:** إضافة مسار `POST /api/contact` وجدول `contact_messages`.

### م4 — لا يوجد Rate Limiting على المسارات العامة
**الحل:** إضافة `express-rate-limit` على مسارات `/api/jobs`.

### م5 — لا توجد وسوم SEO / OpenGraph
**الحل:** إضافة `react-helmet-async` مع وسوم ديناميكية لصفحات الوظائف.
